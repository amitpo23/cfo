# תיוק הוצאות מתור הקליטה בסאמית

מסך `books/fileexpenses` מגיש מסמך אחד בכל פעם מתוך תור הקבצים הממתינים.
ה-OCR של סאמית ("פוענח באמצעות AI 2.0") ממלא אסמכתא, תאריך וסכום — **ושניים מהשלושה
לא אמינים.** הסקיל הזה הוא הנוהל שמתקן אותם לפני שהתנועה נכנסת לספרים.

## שלוש העובדות שמכתיבות את כל הנוהל

**1. ה-OCR משבש את השנה.** היום והחודש נקראים נכון, השנה מוחלפת בשנה נוכחית או עוקבת.
נמדד על עשרות מסמכים: 2021→2025, 2022→2026, 2023→2026, 2024→2025. אין היסט קבוע —
**חובה לקרוא את התאריך מהמסמך עצמו בכל מסמך.** מסמכים משנת השוטפת נקראים נכון.

**2. סאמית מחשבת מע"מ ב-18% תמיד, ולא מחשבת מחדש כשמתקנים את התאריך.**
שיעור המע"מ בישראל: **17% עד 31/12/2024 · 18% מ-01/01/2025**.
לכן כל מסמך שלפני 2025 מקבל מסאמית מע"מ גבוה מדי, והתיקון הוא ידני.
אומת חיצונית: חשבוניות שמפרטות `מע"מ בשיעור: 17%` נתנו בדיוק את המספר המחושב.

**3. תיקון התאריך מנטרל את גלאי הכפילויות של סאמית.**
הגלאי משווה **ת. אסמכתא + 4 ספרות אחרונות של אסמכתא 1 + סכום בש"ח**.
ברגע שהשנה מתוקנת, עותק שני של אותה חשבונית כבר לא מזוהה. חובה לנהל רשימת
`אסמכתא → תנועה` משלך לאורך כל הריצה.

## לפני שמתחילים

טען את `docs/bookkeeper_kb/03-classification-bridge.md` — כללי ההכרה וניכוי התשומות.
הזרק את `references/browser-toolkit.js` לדף (ראה שם הוראות) — הוא מגדיר את כל העזרים.
מיפוי סוגי התנועה לסוגי מסמכים: `references/transaction-types.md`.

## הלולאה — קריאה אחת למסמך

בכל מסמך, בקריאת `browser_batch` אחת:

```
[javascript: __goSafe(תאריך_מהמסמך, סוג_תנועה, יחס_מעמ)] + [screenshot scale 0.5]
```

הצילום מחזיר את המסמך **הבא** — ממנו קורא את התאריך והספק לקריאה הבאה.
כך כל מסמך עולה קריאה אחת. אל תצלם לפני ואחרי; הצילום שאחרי הוא הקלט לצעד הבא.

`__goSafe` מבצע: תיקון תאריך → בחירת סוג → חישוב ותיקון מע"מ → שמירה →
אישור דיאלוג "עריכה ידנית של המע"מ" → מחיקת כפילויות שסאמית סימנה.
הוא **מסרב לשמור** ומחזיר `blocked` בשלושה מקרים (ראה שערים).

## שלושת השערים — לעולם לא לעקוף

| שער | מה הוא תופס | מה עושים |
|---|---|---|
| `MULTIPAGE` | המסמך נושא "הצילום מכיל N דפים" | **לא לשמור.** שמירה תרשום רק את עמוד 1 ותוציא את כל הקובץ מהתור. צריך "פיצול הקובץ לעמודים" קודם — פעולה שדורשת אישור בעלים. |
| `ALREADY_FILED` | האסמכתא כבר תויקה בריצה הזאת | כפילות שהגלאי של סאמית לא יתפוס. לדלג ולרשום; מחיקה רק דרך תצוגת הרשימה. |
| `NO_AMOUNT` | ה-OCR לא חילץ סכום | לקרוא מהמסמך ולמלא ידנית, או להעביר לתור הכרעה. |

## מה לקרוא מכל מסמך

| מה | למה זה קריטי |
|---|---|
| **התאריך** | ה-OCR שגוי. קובע גם את שיעור המע"מ. |
| **שם הספק וסוג המסמך** | `חשבונית מס` מזכה בניכוי תשומות · **`קבלה` בלבד — לא.** |
| **הנמען** | הוצאה על שם צד שלישי אינה הוצאה של העוסק. לסמן, לא לנחש. |
| **שורת המע"מ**, כשהיא נראית | המספר שבמסמך גובר על כל חישוב. |

תצוגת ה-PDF חתוכה בגובה קבוע ומציגה רק את ראש המסמך. "מסך מלא", `2x` וגלילה
אינם מרחיבים אותה. לקריאת תחתית מסמך יש לפתוח את הקובץ עצמו.

## מע"מ — הכרעה לפי סוג ההוצאה

```
מע"מ = סכום × שיעור/(1+שיעור) × יחס
שיעור: 0.17 אם תאריך המסמך < 01/01/2025, אחרת 0.18
```

| הוצאה | יחס | בסיס |
|---|---|---|
| רגילה (שירותים, מחשוב, חשמל, משרד) | 1 | ניכוי מלא |
| **אחזקת רכב משתנות** (דלק, טיפולים, חניה) | **2/3** | תקנה 18 — רכב פרטי |
| רכישת רכב פרטי | 0 | תקנה 14 |
| אירוח, קנסות, ריבית לרשויות, תרומות | 0 | לא מוכר |
| קבלה ללא חשבונית מס | 0 | אין אסמכתא לניכוי |

⚠ יחס הרכב תלוי **בסוג הרכב**, שלרוב לא מופיע בחשבונית התדלוק.
2/3 היא ברירת מחדל שמרנית — לדווח עליה ככזאת, לא כטיפול מאומת.

## מחיקת כפילויות

כשסאמית מסמנת כפילות, הכפתור האדום בשורת הפעולות משתנה מ-`החזרה` ל-**`מחיקה`**
(`a.og-button-color-danger`), ואחריו דיאלוג "מחיקת תנועה" → `אישור`.
המחיקה מסירה את הקובץ מהתור ואינה נוגעת בתנועת היומן הקיימת.

**לפני מחיקה** — לאמת. הבדיקה של סאמית משתמשת ב-4 ספרות אחרונות בלבד;
שתי חשבוניות שונות יכולות להתאים. ההתרעה נושאת קישור "מעבר לתנועה N במנה" —
לפתוח אותה בלשונית נפרדת ולוודא אסמכתא מלאה + סכום + ספק.

`החזרה` אינו מחיקה — הוא מחזיר את המסמך ללקוח/ה.

## honest-null

עמימות אינה ניחוש. מסמך שלא ברור אם הוא עסקי, אם המע"מ שלו פטור, או שהנמען אינו
העוסק — עובר לתור הכרעה עם הנימוק, ולא מתויק. תור ההכרעה הוא תוצר לגיטימי של הריצה.

## דיווח בסיום

לדווח במספרים: כמה נשמרו (עם טווח מספרי תנועה), כמה נמחקו, כמה בתור הכרעה,
וכמה **נשארו**. תור שלא התרוקן אינו "נקי" — לומר זאת במפורש.

## איך סופרים כמה נשאר

**המונה בכותרת מסך התיוק אינו מספר התור.** הוא מוגבל לתצוגת "200+", יורד
מקומית עם כל שמירה בלי לפנות לשרת, וחוזר ל-200+ אחרי רענון. דיווח התקדמות
לפיו ייתן מספר שגוי בסדר גודל.

המספר האמיתי: עמודת **"קבצים לקליטה"** ברשימת התיקים ב-`app.sumit.co.il/books/`.

```js
const tr = [...document.querySelectorAll('table tr')].find(r => /<מספר העוסק>/.test(r.innerText));
[...tr.querySelectorAll('a')].find(a => /fileexpenses/.test(a.href)).textContent.trim();
```

לקרוא אותו **בתחילת הריצה ובסופה**, ולדווח את ההפרש.
