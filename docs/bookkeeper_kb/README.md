## כללי המשמעת

1. **תיוק שוטף** → טען את `03` בלבד. אם הכלל שם חד-משמעי — פעל. אם לא — טען את `01`/`02` הרלוונטי.
2. **לפני דיווח לרשויות** → `02` + `04` + הצ'ק-ליסט הקדם-דיווחי (מודל מכונן 2.3 צעד 11). אימות משולש תמיד.
3. **`03` מיוצר אוטומטית** מ-`src/cfo/services/israeli_tax_rules.py` — לעולם לא לערוך ידנית; שינוי כלל = שינוי בקוד + טסט.
4. **אין מספר בלי ציטוט.** כל סף שסומן ⚠️-לאימות מרוכז ב-`VERIFICATION_NEEDED` שבמודול הקוד — לאמת מול gov.il לפני הסתמכות בדיווח.
5. **honest-null**: עמימות (אירוח או כיבוד? רכב פרטי או מסחרי?) = תור הכרעה, לא ניחוש. הכרעת בעלים ראשונה על ספק נשמרת כתקדים ומוחלת אוטומטית להבא.
6. הצ'אטבוט באפליקציה מגיע לאותו תוכן דרך `rezef_help` (נושאי `tax_rules`, `bookkeeper`) — הכול נרנדר מאותו קוד.
