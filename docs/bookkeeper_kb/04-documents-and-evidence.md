# מסמכים ואסמכתאות — מה קביל, מה נדרש, מה נשמר

**מקורות:** הוראות ניהול ספרים, חוק מע"מ, מרכז ידע SUMIT (כללי 1–11 ב-`docs/SUMIT_KNOWLEDGE_BASE.md`), ייעוץ רו"ח.

## 1. סוגי המסמכים והכוח הראייתי

| מסמך | מס הכנסה (הכרה) | מע"מ (תשומות) |
|---|---|---|
| חשבונית מס | כן | **כן** — המסמך היחיד שמקנה ניכוי (+הקצאה מעל הסף) |
| חשבונית מס-קבלה | כן | כן |
| קבלה בלבד | כן | לא |
| חשבונית עסקה | לא (אינה מסמך הוצאה סופי) | לא |
| דף בנק / אישור העברה | **לא** — ראיה לתשלום, לא להוצאה | לא |
| רשימון יבוא | כן | כן (מע"מ יבוא — כרטיס 40014) |

- החשבונית חייבת להיות **על שם העסק** ולשאת מספר עוסק של הספק.
- "יש תנועת בנק" ≠ "יש הוצאה". תנועה בלי מסמך → כרטיס 99999-בירורים (SOP 2.10), מדווחים בלי הניכוי, ומשלימים בשוטף בחלון 6 החודשים.

## 2. ראיות נלוות נדרשות (לפי קטגוריה)

| קטגוריה | ראיה נוספת חובה |
|---|---|
| רכב | רישום מד-אוץ בתחילת+סוף שנה (תנאי סטטוטורי!); פרופיל רכב (סוג, עיקר-שימוש, צמוד-עובד) |
| אירוח אורח חו"ל | שם האורח, מדינה, ימים, זיקה עסקית |
| מתנות | זהות המקבל + סכום שנתי מצטבר |
| נסיעת חו"ל | מטרה עסקית מתועדת, קבלות לינה, ימי השהות |
| משרד ביתי | תשריט/חישוב שטח, ייעוד בלעדי |
| ציוד מופחת | חשבונית רכישה בתיק הרכוש הקבוע |

## 3. אימות בתיוק (חובה לפני כל תיוק)

1. **ח.פ הספק** מאומת (datagov / company_registry) ותואם את שם הספק על המסמך.
2. **סכום** על המסמך = הסכום הנקלט (±אגורה).
3. **שער כפילויות** (duplicate_gate): ח.פ+אסמכתא זהים = חסימה; סכום+תאריך קרובים = חשד להכרעה.
4. **מספר הקצאה** קיים כשנדרש (מעל הסף — ⚠️ ראה 02 סעיף 4).
5. תאריך המסמך בתקופה פתוחה (רטרואקטיבי → SOP 2.7).

## 4. תקדים-פר-ספק

הכרעת בעלים ראשונה על ספק עמום (אירוח/כיבוד, עסקי/פרטי) נרשמת ומוחלת אוטומטית על מופעים הבאים של אותו ספק. שינוי נסיבות (אותו ספק, שימוש שונה) = הכרעה חדשה. זה מה שמונע מהתור-להכרעה להתמלא בקפה.
