# ניסויי מושקו על ארגון "שף אליהב כהן"

**מטרה:** להפוך את הארגון של אליהב כהן לסביבת הניסויים החיה של מושקו — ארגון אמיתי,
עם תיק SUMIT (מסלול בדיקות, companyid ‏642076960) וחיבור בנק מזרחי דרך Open Finance.

**סטטוס:** טיוטת חיווט — שלבי האימות טרם בוצעו מול הפרוד (אין להניח דבר לפני שלב 0).

## שלב 0 — אימות תשתית (חובה לפני כל ניסוי; קריאות DB בלבד, אפס קריאות ספק)

הבעלים מריץ מקומית (הסודות אצלו; קלוד חסום מגישה ישירה אליהם):

```bash
# 1) מיגרציה לפרוד — שער בעלים לפי GATE0 (טבלאות W1/W2/W6 החדשות)
set -a; source .env.prod; set +a
alembic upgrade head

# 2) אימות הארגון, מפתח SUMIT וחיבור המזרחי (קריאה בלבד)
python - <<'EOF'
import os
from sqlalchemy import create_engine, text
eng = create_engine(os.environ["DATABASE_URL"])
with eng.connect() as c:
    print(c.execute(text("SELECT id, name, is_active FROM organizations ORDER BY id")).fetchall())
    print(c.execute(text("SELECT organization_id, sumit_company_id, is_active FROM sumit_credentials")).fetchall())
    print(c.execute(text(
        "SELECT tablename FROM pg_tables WHERE schemaname='public' AND tablename ILIKE '%connect%'"
    )).fetchall())
EOF
```

תנאי מעבר: הארגון של אליהב קיים ופעיל; יש שורת `sumit_credentials` פעילה עם
‏642076960 (מסלול בדיקות); יש חיבור Open Finance פעיל למזרחי לאותו ארגון.

## שלב 1 — כניסה והקשר ארגוני

   (ה-org_id נכפה מהשרת על כל כלי; למודל אין דרך לעקוף).

## שלב 2 — רענון נתונים לפני ניסוי

- "רענן תובנות עכשיו" (מחזור הבוקר מקומית) — **אפס קריאות ספק**.
- משיכת בנק מזרחי / סנכרון SUMIT — **עולה מכסה**; רק באישור מפורש פר-לחיצה,
  דרך השערים הקיימים (SumitRequestLimiter / תקציב OF).

## שלב 3 — סדרת הניסויים (מהקל לכבד)

| # | ניסוי | מה מאמת |
|---|-------|---------|
| 1 | פתיחת שיחה — האם מושקו פותח בדגלים אדומים? | השכבה הפרואקטיבית (revenue_watch, תזרים שלילי) |
